## Deskripsi Aplikasi
Impactify merupakan aplikasi volunteer berbasis mobile yang dikembangkan untuk membantu proses pengelolaan kegiatan sosial dan volunteer secara digital. Aplikasi ini menghubungkan volunteer dengan penyelenggara kegiatan melalui sistem yang terintegrasi.

Aplikasi menyediakan fitur pencarian event, pendaftaran volunteer, pembayaran, monitoring status seleksi, hingga pengelolaan kegiatan oleh admin atau penyelenggara.

---

## Fitur Aplikasi

### Fitur User (Volunteer)
- Registrasi akun
- Login akun
- Menjelajahi event volunteer
- Melihat detail event
- Pendaftaran kegiatan volunteer
- Pembayaran kegiatan
- Monitoring status seleksi
- Mengelola profil pengguna
- Mengakses sertifikat digital

### Fitur Penyelenggara
- Login penyelenggara
- Dashboard admin
- Menambah event
- Mengedit event
- Menghapus event
- Verifikasi pembayaran
- Mengelola peserta
- Mengatur sertifikat
- Melihat laporan analitik

---

## Implementasi CRUD
Aplikasi telah menerapkan operasi CRUD (Create, Read, Update, Delete) menggunakan SQLite sebagai database lokal.

### Create
Menambahkan data event volunteer baru ke database.

### Read
Menampilkan seluruh data event yang tersimpan.

### Update
Mengubah data event berdasarkan ID.

### Delete
Menghapus data event dari database.
